# Aluga Top
Projeto full-stack de um sistema de alugueis de casas

<img src="/public/rent.png" alt="url">

## Funcionalidades

- Login e Autenticação
- criação de anúncios
- Edicão do anuncio
- Exclusão do anuncio
- Responsividade
- Visual Dinamico

## Stack utilizada

Next, React, TypeScripit, Postgresql, Axios, Api, Next-UI, Tailwind, SCSS, Node, Prisma, Express, bcrypt, jsonwebtoken
